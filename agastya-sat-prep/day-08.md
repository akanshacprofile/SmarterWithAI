## MATH LESSON (15 min)

### Topic: Function Notation and Transformations

#### Function notation basics
`f(x) = 2x + 3` is a rule. `f(4)` means "plug in 4." → 2(4)+3 = 11.

#### Composite functions
`f(g(x))` means: first apply g, then apply f to the result.
- If `f(x) = x + 2` and `g(x) = 3x`, then `f(g(2)) = f(6) = 8`.

#### Inverse functions
`f⁻¹(x)` undoes f. To find: swap x and y, then solve for y.
- If `f(x) = 2x + 1`, write y = 2x+1 → swap → x = 2y+1 → y = (x−1)/2 → **f⁻¹(x) = (x−1)/2**

#### Transformations of f(x)
| Transformation | Effect |
|---|---|
| f(x) + k | shift UP by k |
| f(x) − k | shift DOWN by k |
| f(x + h) | shift LEFT by h |
| f(x − h) | shift RIGHT by h |
| −f(x) | reflect over x-axis |
| f(−x) | reflect over y-axis |
| a·f(x) | vertical stretch by a |

#### Worked example 1
If `f(x) = x²`, what does `g(x) = (x − 3)² + 4` look like?
- Shift f RIGHT 3, UP 4. Vertex at (3, 4).

#### Worked example 2
If f(2) = 7 and g(x) = f(x) − 5, what is g(2)?
- g(2) = f(2) − 5 = 7 − 5 = **2**

#### Speed tip
The "trick" with `(x − h)` shifting RIGHT (not left) catches everyone. Memorize: **the sign inside is opposite the direction**.

## ENGLISH LESSON (15 min)

### Topic: Parallel Structure

**Rule:** Items in a list, comparison, or pair must share the same grammatical form.

#### Lists
- ❌ "She likes swimming, hiking, and to bike." (gerund, gerund, infinitive)
- ✓ "She likes swimming, hiking, and biking."
- ✓ "She likes to swim, to hike, and to bike."

#### Comparisons (with "than" or "as ... as")
- ❌ "Her writing is clearer than her brother." (compares writing to brother)
- ✓ "Her writing is clearer than **her brother's**." (writing to writing)

#### Correlative conjunctions (must be parallel)
- *Both X and Y* — X and Y same form
- *Either X or Y* — same form
- *Neither X nor Y* — same form
- *Not only X but also Y* — same form

Examples:
- ❌ "She is not only smart but also works hard."
- ✓ "She is not only smart but also hardworking."
- ✓ "She not only studies hard but also works hard."

#### SAT pattern
When you see *both, either, neither, not only, rather than*, look across to make sure both parts are the same form.

#### Speed tip
Read both sides of the conjunction aloud. If they don't sound symmetric, they're not parallel.
